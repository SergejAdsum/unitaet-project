# Unitaet

Unitaet is a digital platform and social network created for Russian Germans and people interested in family history, genealogy, heritage and cultural identity.

The platform helps families preserve their history together through:

- Family groups
- Shared family feeds
- Genealogy tools
- Historical archives
- Community interaction
- Cultural projects

Official website:
https://unitaet.com

Main topics:
Russian Germans, genealogy, family history, German heritage, identity, archives, social network.
